# 春秋戦国 — ブラウザ RTS

春秋戦国時代（前770年〜前221年）の中国を舞台にした、Age of Empires 風のリアルタイムストラテジー。
TypeScript + Canvas 2D のみで実装した静的サイトで、Cloudflare（Workers Static Assets / Pages）でそのまま配信できる。

## 遊び方の要点

- 最初に 41 か国（春秋時代の実在の国・異民族。都は史料上の比定地に配置）から 1 国を選ぶ。
- **時間軸はマップ全体で共有**。1 年 = 6 秒（等速）、一時停止・2/4/8 倍速あり。
- 工人が平原（糧）・森林（木）・鉱山（金）で採集し城へ運ぶ。採集できるのは自領か無主地のみ。
- **ユニット数の上限は少なめ**（城の数・城レベルで増える。工人最大 14、兵最大 20）。
  代わりに **訓練** で各ユニットの能力（兵力 / 採集力）を高める。能力上限は時代で全国共通（春秋 250 / 戦国 400）。
- **軍事ユニットは存在するだけで糧を消費**（能力に比例）。糧が尽きると兵が逃亡する。
- 軍事ユニットを **解散して工人** に、工人を **徴兵して兵** にできるが、能力は **2/3** に目減りする。
- 兵種: 歩兵・戦車・弓兵（戦国期は弩兵）・騎兵（前307年 胡服騎射以降）。相性あり。
- 工人で新たな城を築ける（他の城から一定距離が必要）。城は強化すると城壁・領域・兵の上限が増える。

## 歴史イベント

| イベント | 時期 | 内容 |
| --- | --- | --- |
| 覇者の呼びかけ | 春秋 | 周辺国を攻撃し続けると「諸侯の警戒」が溜まり、閾値を超えると覇者（最有力の周辺国）が諸侯を糾合し、10 年間一斉に攻撃してくる |
| 戦国時代の到来 | 前475年 | 鉄器の普及で全国一律に攻撃力・生産力が向上、弓兵が弩兵に |
| 三家分晋 | 前403年 | 晋が存続していれば韓・趙・魏に分裂（晋を選んだ場合は最大の継承国を引き継ぐ） |
| 胡服騎射 | 前307年 | 全国で騎兵が編成可能に |
| 合従軍 | 戦国 | 最も強大な国（国力が 2 位の 1.15 倍以上、または全体の 20% 以上）に対し、周辺諸国が 12 年間一斉に攻撃する |

文明の進歩は特定の国だけに起こらず、全国同時に訪れる。
戦国七雄の系譜にある国（秦・楚・斉・燕・晋→韓趙魏）は **生産能力の補正**（×1.35〜1.45、小国は ×0.7〜1.0）と城の堅さの補正を持ち、生き残りやすい。

## 操作

| 操作 | 内容 |
| --- | --- |
| 左クリック / ドラッグ | 選択（Shift で追加） |
| 右クリック | 移動・採集・攻撃・建設支援 |
| ホイール / 中ボタンドラッグ / 矢印キー / ミニマップ | 拡大縮小・視点移動 |
| `A` | 攻撃移動（途中の敵と交戦しながら進軍） |
| `B` | 築城（工人選択時） |
| `Q` / `E` | 全軍選択 / 待機中の工人選択 |
| `H` | 都へ |
| `Space` | 一時停止 |
| スマホ | 1 本指スクロール、2 本指ピンチ、タップ選択、「命令モード」ON でタップ命令 |

宣戦布告・講和は「諸国」ボタン、または他国の城を選択したパネルから行う。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 型チェック + dist/ へビルド
npm run sim -- 7   # 全 AI 対戦をヘッドレスで最後まで回すバランス確認（引数はシード）
```

## Cloudflare へのデプロイ

- **Workers（静的アセット）**: `npx wrangler login` 後に `npm run deploy`（`wrangler.toml` 参照）。
- **Pages**: リポジトリを接続し、ビルドコマンド `npm run build`、出力ディレクトリ `dist` を指定。

## 構成

```
src/
  config.ts        定数・兵種・コスト
  data/states.ts   諸国と都市（経緯度）、生産補正
  data/geo.ts      海岸線・河川・湖・山脈の簡略地理データ
  map.ts           地形生成・A* 経路探索
  game.ts          シミュレーション本体（経済・戦闘・外交・イベント）
  ai.ts            AI（経済・築城・軍備・宣戦/講和）
  render.ts        Canvas 描画・ミニマップ
  ui.ts            入力・パネル・諸国一覧
  main.ts          開始画面・ゲームループ
scripts/sim.ts     ヘッドレスのバランス検証
```
